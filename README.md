# 功夫派存档修改器（chengyi-updatepai）

> 《功夫派 XiewaPai》单机存档编辑器，Java 桌面程序，支持游戏 V1.1.x / V1.2.0。
>
> 一句话说明：可视化调整存档里的货币、道具、装备、保底、掉落等数值，内置**自动备份 + 一键还原**，改坏了随时能还原回改之前的状态。

## 功能总览

这是一个图形化（Swing）桌面程序，读取本地存档后，在界面里直接改数值、点保存即写回。支持的功能模块包括：

- **货币**：通宝、金币等各类货币的查看与调整
- **道具**：背包 / 仓库道具的增减、堆叠数量调整
- **装备**：装备的添加、强化品质调整
- **保底**：抽卡 / BOSS 掉落保底进度的查看与调整
- **掉落通道**：掉落相关的数值调整
- **商城解锁**：商城档位的查看与调整
- **账号体检**：查看存档健康状态与相关限制提示

## 核心能力

- **改前自动全量备份**：每次写入前，把「改之前」的存档 + 相关缓存 + 注册表状态，整体收进 `backups/<账号ID>/<时间戳>/`，保留最近 2 天
- **一键还原**：从备份时间点选择还原，覆盖回改之前的状态
- **内置安全上限**：各道具/材料/装备有内置的数值上限与审计，避免改出非法数据
- **游戏运行中防呆**：检测到游戏正在运行时，禁止写入，避免被游戏内存旧状态覆盖
- **密钥本机实时解析**：读取存档时用当前 Windows 用户的 DPAPI 解 `profile.cfg`，支持 1.1.1 起的新版 `XWD3` 信封；密钥只在内存中，**不写盘、不打包、不收集**
- **多账号自动识别**：本机 `%APPDATA%\Ombrel\rt\saves` 下的所有账号都会列出来，不再依赖预置密钥

## 密钥说明

存档用 AES-256 加密，密钥由游戏随机生成，并交给 Windows DPAPI 保护。本程序**不内置、不收集、不保存**任何密钥：

- 每次读取存档时，用当前 Windows 用户的 DPAPI 现场解出该账号的密钥，解完只在内存里用。
- 支持新版 `XWD3` 信封（游戏 1.1.1 起），也兼容旧版单个 DPAPI blob。
- 如果程序找不到游戏 exe，可在程序目录或 `%APPDATA%\chengyi-updatepai` 放一个 `gamepath.txt`，第一行写 `XiewaPai.exe` 的完整路径；也可以设置环境变量 `XIEWAPAI_EXE`。

> DPAPI 绑定「这台电脑 + 这个 Windows 用户」。所以换电脑时，需要在那台电脑上用同一个 Windows 用户运行过游戏/登录过对应账号；只把别人的 `save.dat` 拷过来、没有对应账号在本机的解密环境时，任何不保存密钥的程序都无法解密。

## 环境要求

| 项 | 要求 |
|---|---|
| JDK | 21（`JAVA_HOME` 指向 jdk-21） |
| 构建工具 | Maven（可用 IDEA 内置 `plugins\maven\lib\maven3\bin\mvn.cmd`） |
| 打包 | `jpackage`（JDK 自带） |
| 运行平台 | Windows |

## 构建与打包

### 1. 编译打包 jar

```bash
# Windows（使用 IDEA 内置 Maven）
set JAVA_HOME=C:\Program Files\Java\jdk-21
mvn clean package -DskipTests
```

产物：`target/xiewa-save.jar`

### 2. 打可执行 exe（app-image）

用 `jpackage` 生成免安装目录版：

```bash
jpackage --type app-image \
  --input target/jpkg \
  --main-class com.chengyi.xiewa.save.XiewaEditorApp \
  --name chengyi-updatepai \
  --dest dist
```

> 注意：`--input` 指向的目录里**只放 `xiewa-save.jar`**（先把它单独拷进 `target/jpkg`），否则打包会把无关依赖一并打进去。

### 3. 一键脚本

直接运行 `build-exe.cmd`（Windows）或 `build-exe.sh`，会自动完成上面的编译 + 打包流程。

### 打包前注意

- 确认游戏与修改器进程都已关闭（目录占用会导致 `jpackage` 失败）
- 产物输出在 `dist\chengyi-updatepai\`，日常直接运行其中的 `chengyi-updatepai.exe`

## 使用说明

### 启动前准备

1. **完全退出游戏**（否则界面会提示「游戏运行中不允许修改」）
2. 双击 `chengyi-updatepai.exe` 启动修改器

### 基本流程

1. 程序自动定位本机存档（无需手动选路径）
2. 在界面各标签页里查看 / 修改目标数值
3. 点「保存」：
   - 自动先把「改之前」的完整状态备份进 `backups/<账号ID>/<时间戳>/`
   - 写入存档并同步相关缓存状态
4. 重新打开游戏，验证数值已生效

### 一键还原

- 在备份列表里选择某个时间戳备份点
- 点还原，程序会用该备份覆盖当前存档与相关状态
- 备份保留最近 2 天，更早的会自动清理

## 注意事项

1. **改档 / 还原前必须完全退出游戏**，否则游戏退出会用内存旧状态覆盖你的修改
2. 不要在游戏运行时对存档做任何外部改动
3. 数值不要超过界面提示的上限，超出可能无法正常读取
4. 每次修改都会自动备份，改坏了用「一键还原」即可回到之前状态
